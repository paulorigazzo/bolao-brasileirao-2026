## Legenda padrão de status

- ✅ **Concluído** — implementado e validado.
- 🟡 **Em andamento** — desenvolvimento ativo.
- 🔵 **Parcialmente implementado** — existe uma base funcional, mas o item ainda não está completo.
- ⬜ **Planejado** — aprovado e ainda não iniciado.
- 🔮 **Visão de longo prazo** — ideia futura, sem compromisso de versão imediata.

## Política de atualização

1. Atualizar o `ROADMAP.md` quando um item mudar de prioridade, versão ou status.
2. Registrar entregas no `CHANGELOG.md`.
3. Registrar decisões relevantes no `PRODUCT_LOG.md`.
4. Ajustar o `RELEASE_PLAN.md` quando o escopo de uma versão mudar.
5. Manter o `AI_STRATEGY.md` alinhado ao roadmap de IA.
