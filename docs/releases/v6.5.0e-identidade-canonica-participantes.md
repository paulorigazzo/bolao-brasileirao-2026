# v6.5.0e — Identidade canônica dos participantes

Correção transversal para impedir registros duplicados quando um participante altera o nome de exibição.

O aplicativo agora constrói aliases entre nomes históricos e o nome atual usando `user_id`, normalizando palpites públicos, contagens, ranking, Home, estatísticas e demais componentes antes da renderização. Nenhum palpite encerrado é alterado no banco.
