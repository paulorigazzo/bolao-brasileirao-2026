# v6.6.0 — Projeto JARVIS

## Objetivo

Refinar e implementar a identidade visual oficial do Bolão Brasileirão 2026, baseada na Série 4.1 aprovada. JARVIS é exclusivamente o codinome interno da nova marca.

## Entregas

- escudo principal vetorial;
- símbolo reduzido para cabeçalho, favicon e PWA;
- versão monocromática;
- tela de carregamento e apresentação com a nova marca;
- ícones PWA em 192 e 512 pixels;
- imagem social para compartilhamento;
- metadados, manifesto e cache atualizados;
- documentação de uso da marca.

## Limites da versão

Nenhuma regra de negócio, integração, banco de dados ou funcionalidade foi alterada.
