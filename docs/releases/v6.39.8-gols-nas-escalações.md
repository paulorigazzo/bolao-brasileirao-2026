# v6.39.8 — Gols nas escalações

## Objetivo

Facilitar a identificação dos autores dos gols dentro das escalações e suavizar os indicadores sobre o campo, sem acrescentar consultas ou alterar os dados esportivos.

## Entrega

- ícone de bola e minuto associados ao autor do gol nas visualizações Lista e Campo;
- mesma indicação disponível no banco quando o gol pertence a um reserva que entrou;
- suporte compacto a múltiplos gols, acréscimos, pênaltis `(P)` e gols contra `(GC)`;
- fundo dos eventos no Campo com transparência ampliada;
- associação dos gols pelo identificador oficial do jogador, inclusive quando um gol contra beneficia o adversário.

## Preservações

Permanecem inalterados o placar, a lista principal de autores dos gols, a formação inicial, a API, o Supabase, palpites, pontuação, Ranking e demais telas.

## Validação

- `npm run test:lineup-match-events`;
- `npm run test:lineup-pitch`;
- `npm run check`;
- revisão visual em celular e desktop no Deploy Preview.
