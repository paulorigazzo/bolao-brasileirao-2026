# v6.24.4 — Escudos locais da API-Football

## Objetivo

Eliminar a dependência do navegador dos participantes em relação ao domínio
`media.api-sports.io`, preservando a API-Football como origem dos escudos.

## Contexto

O primeiro corte da Fase 6D sincronizou corretamente os dez jogos da rodada 26,
mas os escudos desapareceram para participantes cujo resolvedor retornava
`NXDOMAIN` para o domínio de mídia. O diagnóstico permaneceu em `100/100`
porque comprovava a presença das URLs, não o carregamento das imagens.

O rollback restaurou a football-data.org, os 380 jogos e os escudos, sem perda
dos 50 palpites da rodada 26.

## Entrega

- vinte PNGs originados na API-Football são publicados em
  `/assets/clubs/api-football/<team-id>.png`;
- jogos e classificação da API-Football usam somente essas URLs locais;
- um script reprodutível baixa por DNS público e valida tipo, assinatura,
  tamanho e resolução antes de substituir os arquivos;
- o diagnóstico consulta os vinte ativos na mesma origem do Bolão;
- o preflight falha se a cobertura ou a disponibilidade local estiver
  incompleta.

## Preservações

Não há migração de banco, alteração de RLS, autenticação, palpites, pontuação,
identificadores, resultados ou horários. A football-data.org permanece como
fonte oficial; esta versão não executa novo corte.

## Operação

Atualização controlada dos ativos:

```powershell
npm run sync:api-football-local-crests
```

O comando deve ser seguido por `npm run check` e revisão visual em Deploy
Preview antes de qualquer autorização de corte.
