# v6.4.0 — Meu Time 2.0

A versão transforma a preferência de time favorito em um eixo transversal do produto.

## Entregas

- Nova tela Meu Time;
- contexto central derivado dos dados existentes;
- próximo jogo e forma recente;
- desempenho pessoal;
- Índice de Sintonia;
- Perfil do Torcedor;
- timeline da temporada;
- conquistas;
- integração com Home, Jogos e Tabela.

## Regra de produto

A personalização é emocional e informativa. Nenhum cálculo altera as regras de pontuação ou cria vantagem competitiva.
