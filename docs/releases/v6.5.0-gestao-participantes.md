# v6.5.0 — Gestão de Participantes

## Objetivo

Permitir que cada participante mantenha seus próprios dados e criar um fluxo seguro de entrada por link com aprovação posterior do administrador.

## Entregas

- edição do nome de exibição pelo próprio participante;
- celular com WhatsApp opcional, armazenado de forma normalizada;
- e-mail Google preservado como dado não editável;
- link de cadastro compartilhável (`?cadastro=1`);
- solicitação de participação após login Google;
- estados pending, approved, rejected e inactive;
- tela de espera para cadastros ainda não aprovados;
- aprovação ou recusa na Área ADM;
- dados de celular visíveis apenas ao próprio usuário e ao administrador;
- atualização do nome histórico dos palpites pelo `user_id`;
- migração SQL disponibilizada em `.sql` e `.txt`.

## Implantação

Antes de publicar o novo pacote, execute no SQL Editor do Supabase:

`supabase/migrations/20260728_v6_5_0_gestao_participantes.sql`
