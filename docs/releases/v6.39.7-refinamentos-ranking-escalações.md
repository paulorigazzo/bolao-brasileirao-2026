# v6.39.7 — Refinamentos de ranking e escalações

## Objetivo

Reduzir ambiguidades na classificação e melhorar a leitura das escalações em celulares, sem alterar dados ou regras competitivas.

## Entrega

- acesso ao Ranking provisório visível aos participantes somente durante partidas oficialmente ao vivo com placar;
- alias `Paranaense` associado ao tema rubro-negro do Athletico-PR;
- banco de reservas organizado como as escalações titulares, com números, nomes e eventos espelhados por time;
- posições laterais do campo deslocadas para uma margem segura;
- etiquetas de eventos dos jogadores das pontas direcionadas para o centro do campo;
- área dos nomes ligeiramente ampliada no celular.

## Preservações

Permanecem inalterados o cálculo do Ranking provisório, o Ranking oficial, a formação tática, a API, o Supabase, placares, palpites, pontuação e demais telas.

## Validação

- `npm run test:temporary-ranking`;
- `npm run test:lineup-pitch`;
- `npm run test:lineup-match-events`;
- `npm run check`;
- servidor local e revisão visual em celular e desktop.
