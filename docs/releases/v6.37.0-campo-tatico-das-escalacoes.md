# v6.37.0 — Campo tático das escalações

## Objetivo

Oferecer uma leitura visual da formação inicial sem substituir a lista de titulares já validada.

## Entrega

- seletor acessível `Lista | Campo` dentro do expansível de Escalações;
- lista preservada como opção inicial;
- campo vertical com mandante e visitante simultaneamente;
- camisas vetoriais com número e nome compacto dos titulares;
- posicionamento derivado exclusivamente da coordenada `grid` fornecida pela API-Football;
- retorno seguro à lista quando os 22 titulares não possuem coordenadas válidas e únicas.

## Preservações

Não há alteração em banco, migrações, coleta, sincronização, placares, status, palpites, pontuação ou Ranking.

## Validação

- `npm run test:lineup-pitch`;
- `npm run check`;
- revisão visual em desktop e celular com os dados da Rodada 26.
