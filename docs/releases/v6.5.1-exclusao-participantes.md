# v6.5.1 — Exclusão de participantes

A Área ADM recebeu a ação **Deletar**, destinada a remover permanentemente todos os dados de um participante dentro do bolão.

## Dados removidos
- palpites e pontuação derivada;
- perfil do participante;
- cadastro/autorização de acesso.

A conta Google/Supabase Auth permanece existente. Caso a pessoa use novamente o link de cadastro, poderá solicitar uma nova participação.

## Proteções
- somente administradores aprovados e ativos;
- confirmação em duas etapas;
- digitação exata do nome;
- bloqueio da exclusão do próprio administrador;
- bloqueio da exclusão de outro administrador pela interface.

## Migração obrigatória
Execute `supabase/migrations/20260728_v6_5_1_exclusao_participante.sql` antes da publicação.
