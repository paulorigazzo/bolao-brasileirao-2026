# v6.24.6 — Identidade visual uniforme dos clubes

## Objetivo

Fazer a Classificação apresentar os clubes com os mesmos nomes usados nas
demais telas e impedir novas trocas entre nomes, siglas, IDs e escudos.

## Entrega

- `Mineiro` é apresentado como `Atlético-MG` na Classificação;
- `Paranaense` é apresentado como `Athletico-PR` na Classificação;
- a conversão alcança cartões móveis, tabela desktop e o texto da ação
  expandida de jogos do clube;
- os nomes internos continuam preservados para busca, favoritos e associação
  com partidas;
- uma matriz de regressão registra os vinte clubes, IDs da API-Football, nomes
  recebidos, nomes canônicos, nomes de exibição, siglas e assinaturas dos PNGs;
- os testes passam a falhar se um escudo for trocado de ID.

## Preservações

Não há alteração em banco, RLS, autenticação, API oficial, classificação
competitiva, palpites, pontuação, arquivos de escudo ou configuração da
Netlify.
