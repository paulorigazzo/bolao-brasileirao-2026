# v6.38.0 — Camisas dos clubes no campo tático

## Objetivo

Facilitar a identificação dos times no campo das escalações sem depender de fotografias ou imagens adicionais.

## Entrega

- camisas vetoriais com cores associadas aos clubes;
- padrões simples sólidos, listrados, com faixas ou mangas contrastantes;
- combinações de três cores para Bahia, Fluminense, Fortaleza, Grêmio e São Paulo;
- cobertura dos 20 clubes da temporada, incluindo Chapecoense, Coritiba e Remo;
- número com cor e sombra definidas para preservar a leitura;
- fallback neutro para clubes ainda não cadastrados.

## Preservações

Não há alteração em API, Supabase, coleta, sincronização, escalações, posicionamento, placares, palpites, pontuação ou Ranking.

## Validação

- `npm run test:lineup-pitch`;
- `npm run test:game-details`;
- `npm run check`;
- revisão visual em desktop e celular com os dados da Rodada 26.
