# v6.5.2 — Simplificação do menu do usuário

A opção redundante **Meu time** foi removida do menu da conta.

A navegação passa a seguir esta organização:

- **Meu perfil** no menu do usuário: edição de nome, celular, e-mail e preferências;
- **Meu Time** na barra principal: acompanhamento do clube, desempenho, sintonia e conquistas.

Nenhuma funcionalidade foi removida.
